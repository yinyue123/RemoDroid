AI assistants (MCP)

Let Claude, ChatGPT or another AI assistant use your phone: read the screen, take screenshots, and tap, type and swipe, the same things you do in the viewer. It connects through MCP (Model Context Protocol), the standard way to give an assistant tools.

3. Make a token

The assistant signs in with an API token, not your password. Make one per assistant, so you can revoke one without touching the others.

5. Try it

Ask in plain words. The assistant reads the screen first, then acts and checks the result after each step.

  • “What's on my phone's screen right now?”
  • “Open Settings and tell me which Android version the phone runs.”
  • “Turn on Wi-Fi.”
  • “Open YouTube and search for lo-fi music.”

Good to know

  • You come first. While you're touching the phone in the viewer, the assistant's taps are refused for 5 seconds and it is told to wait.
  • Screen text is data. Assistants are told that text on the phone (messages, web pages) is content, never instructions to them.
  • It asks before risky taps. Tapping and typing are marked as actions with side effects, so Claude Code and ChatGPT ask you before running them unless you allow them.
  • Computers too. On a Windows, macOS or Linux computer the assistant sees the screen through screenshots and uses the mouse and keyboard. The person at the computer is told when an assistant starts. A view-only computer can only be looked at, and one that asks before every viewer is off-limits to assistants.
  • Sign-ins are revocable. claude.ai and ChatGPT get a token for one phone when you tap Allow. It shows under Server → API tokens; revoke it there to cut them off.
