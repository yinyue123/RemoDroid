## 可复用操作方法

解锁：`python3 skills/phone-unlock/run.py`。密码已按用户要求保存在该脚本中，不再重复索要。

其余操作使用 `python3 skills/phone-unlock/connection.py ...`，它自动进入 namespace1 并读取现有认证配置。HTTP API 通过到 `sz` 的 SSH 转发访问，避免共享公网 IP 上其他登录失败导致的 429 限流。

打开微信：`launch com.tencent.mm`。本机微信的 UI 树为空，即使 `--full --all-windows` 也只有系统栏，所以按 phone skill 的稀疏界面分支使用截图。依据当前截图定位坐标，使用 `tap --xy X Y --image W H`；不要跨页面沿用旧坐标。

本次截图尺寸 548×1280：聊天列表“夜雨彩虹”在约 (181,348)，聊天输入框在键盘关闭时约 (200,1180)，输入后 Send 按钮在约 (499,769)。这些只是本次位置，重放前必须重新看画面。

输入中文用 `text 你好`，现有 API 会通过剪贴板粘贴。发送前核对联系人和输入内容，发送后检查消息气泡。后续回复必须是这条出站消息之后的新入站消息，不能把历史“你好”当成回复。用户已经明确授权这次两条消息，无需再次请求发送确认。
